# Curated Repository Collection

Personal collection of third-party repositories. Use the descriptions to find candidates, then fetch the repository and inspect the relevant documentation or code. License labels are repository-level GitHub metadata checked on 2026-11-14, not a guarantee for every file; `Unidentified` means GitHub did not identify a standard SPDX license. Check the actual license and component terms before use or reuse.

## Legend

- **Skill**: instructions, workflows, or tools for coding agents.
- **UI**: interface components, interaction patterns, icons, or visual systems.
- **App**: complete applications and product workflows.
- **Tool**: developer utilities, CLIs, or integrations.
- **Runtime**: execution environments, sandboxes, or agent infrastructure.
- **Data**: databases, storage, caching, and data processing libraries.
- **Library**: reusable programming interfaces or frameworks outside the above categories.
